# 实拍校正后的两辆模型

这轮修改已进入实际几何、材质和可编辑工程。参考来源与未测量部分保留在各车的制作说明中。所有展示图均由交付模型直接渲染，没有使用生成式修图来补车体。

## 打开与使用

- [NIU 模型](NIU_NXT_Ultra_2025/NIU_NXT_2025_Refined.blend)、[Q70C 模型](Ninebot_Q70C/Ninebot_Q70C_Refined.blend)：可编辑的分件模型和预览相机。
- [NIU 棚拍场景](NIU_NXT_Ultra_2025/NIU_Product_Studio.blend)、[Q70C 棚拍场景](Ninebot_Q70C/Q70C_Product_Studio.blend)：本轮统一棚拍场景，主相机已设为 4096×3072。用 Blender 打开后可直接渲染。
- `.glb`：闭合状态的便携模型。Blender 的程序化材质和细微纹理应以原生工程为准。
- Q70C 时间轴第 **1 帧闭合、第 45 帧打开坐垫**；坐垫底壳、筋、锁环随前端铰接转动。GLB 为第 1 帧的静态导出。
- 两辆车采用米制、车头 +X、向上 +Z，并保留车体集合和根节点。生成脚本与依赖的同目录 Python 文件一并提供。

`展示图` 中主图为 4096×3072，其余视角为 2400×1800；`前后对比`使用同一套灯光和机位。各车自带的 1200px 图用于记录细节检查。

## NXT Ultra 2025 黑色短座版

按拆解片重做共用横框内的三个主要光学区、独立透明灯盖、环灯、带凸肋载板与外罩，清除了旧单中心投射筒。补做仪表罩、双圆镜、前内围储物口、贴合的检修盖和挂钩。座桶成为独立开口部件，加入短座底壳和前铰链；刹车盘具有内开窗、连接臂和独立 ABS 环。

前围回边、内衬及下裙连接重新处理，修复了切孔造成的跨踏步补面、悬空盖板和侧边透光缺口。黑色短座与后伸货架继续依据官网配置，银白长座实拍仅用于共享零件细节。

主要参考：[黑色短座门店实拍](https://www.douyin.com/video/7575140258804749903)、[2025 拆解片](https://www.douyin.com/video/7543589660329561359)、[同款试驾](https://www.douyin.com/video/7528096986893913379)。

## Q70C 柠檬黄

v0.1.1 去掉坐垫外露黑色滚边，内收底壳；前挡泥板重建为短前口、深侧裙罩壳，反光片重新贴合白色侧壁。详见 [更新记录](CHANGELOG.md)。

重建圆润侧盖及前挡泥板、浅灰管状扶手、前鼻下垂的坐垫、连续黄色座台与完整黑色座桶。外壳、口沿与内腔共用同一周界，避免闭合露桶或开口穿插。补做驾驶区内面、凹槽/挂钩、按钮布局、地台盖板及座垫底壳，尾灯重建为贴壳的红色圆角矩形环和黑色内面。

同时修正地台接合平面错误的平滑法线，消除高清图上的星状碎反光。

主要参考：[柠檬黄装配实拍](https://www.douyin.com/video/7633436353291877233)，并结合上一轮资料包的小红书尾部与拆座照片。

## 尺寸与验证

Q70C 实际网格的轴距保持 1.110 m，指定骑乘接触点的座高保持 0.730 m。NXT 保持既有官网侧图标定，实际轴距约 1.244562 m、座面采样约 0.738–0.741 m；这些 NXT 数值仍属于图像重建标定，未升级为厂方公布尺寸。

独立验证检查了实际网格坐标、根节点层级、座面与轴距，并重新导入 GLB 对比边界。NXT 还检查了踏步空间和前围侧边缺口；Q70C 检查了闭合射线命中坐垫、打开后命中桶底。逐项结果见各车的 `independent_validation.json` 和原生验证记录。

目前仍有未测量的车壳横截面、壳厚、附件连接尺寸和微小光学细节。这是一轮有实拍依据的优化成果，尚不能称为已经核实到原厂数据的完美复刻。

## 重新生成与渲染

在对应车目录运行 Blender 后台脚本即可重建。下面为 macOS 的安装路径示例；其他平台或已配置 PATH 时可用 `blender` 替换完整路径：

```sh
"/Applications/Blender.app/Contents/MacOS/Blender" -b --python-exit-code 1 --python build_q70_refined.py
```

统一展示与独立校核脚本放在 `tools` 中，分别运行 `render_views.py --help`、`verify_and_export.py --help` 查看脚本参数时，应通过 Blender 并在 `--` 后传参。文件清单和 SHA-256 见包内《文件清单与校验.json》。
