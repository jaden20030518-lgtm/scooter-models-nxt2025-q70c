# Q70C 柠檬黄实拍重建

v0.1.1 修正坐垫外缘与前挡泥板，见 [局部对比](Q70C_座垫与挡泥板修正.jpg)。

本目录是独立新版，未覆盖 `Production_Q70C`。

打开 `Ninebot_Q70C_Refined.blend` 即可继续编辑。时间轴第 1 帧是闭合状态，第 45 帧是前翻 78° 的打开状态；控制对象为 `SEAT_OPEN_CONTROL`。坐垫外皮、注塑底壳、加强筋与锁环随铰接控制一起运动。完整生成器是 `build_q70_refined.py`，用 Blender 后台执行即可重建；设置环境变量 `Q70_NO_RENDER=1` 可只生成场景。

本轮依据实际解码并人工审阅的抖音视频 `7633436353291877233`，重点使用 11.300s 侧面、54.700s/62.050s 座桶与坐垫底壳、183.250s/185.175s 驾驶区；后部由小红书 `6a2eaebf0000000022029594` 第 1、2 张装配照片补充。不同来源是不同车辆，内部配置只作可见结构参考。

主要改动：

- 奶白侧盖改为有完整圆润边界和横向鼓度的曲面；下缘平缓，尾端不再尖收。
- 浅灰哑光后扶手，补充实际可见的后部支架层级。
- 坐垫顶面平顺，保留前鼻圆垂；外缘为棕色包覆，没有外露黑色滚边。黑色底壳收在坐垫内侧，保留交叉加强筋、前翻铰接与锁环。
- 黄色外侧座台、环形口沿与黑色座桶使用同一组周界，避免外壳与桶口交叉。座桶是有真实深度的空腔。
- 前挡泥板按官方图片及实拍 6.500s / 11.300s 改为深侧裙罩壳，前口缩短，中后段向下包覆，反光片及薄底座贴在白色侧壁上。驾驶区保留灰色按钮、紧凑镜杆和内面储物凹区/挂钩/检修盖。
- 黄色地台可拆盖板与细缝、浅槽；后灯改成曲面贴合的横向圆角红环与黑色中心。
- 仪表采用未通电的深色反射屏面，不照搬宣传贴膜或臆造显示 UI。橙色手把光环对应视频中的一个灯光状态。

轴距保持 1.110 m；指定骑乘接触点的坐高保持 0.730 m。`verify_native.py` 检查实际求值几何、打开/关闭状态的座桶可达性、对象层级和有限坐标。GLB 已完成导出和回读；结果见 `independent_validation.json`。

仓库预览由当前统一棚拍图缩小得到，最长边 1200 像素。相机包括 `Q70C_HERO`、`Q70C_SIDE`、`Q70C_OPEN_SEAT`、`Q70C_DRIVER`、`Q70C_REAR_REFINED`。4K 主图及 2400px 细节图已保存在 `展示图/`。`preview_visual_audit.json` 对应当前版本预览；当前文件指纹见主清单。

限制：这是由实拍和公开图片重建的可编辑展示模型，不是工厂 CAD。宽度、厚度、隐藏连接件与内部深度仍有估计；座桶加强筋是依据可见结构重建，并非逐点实测。不得用作生产加工依据。

`verify_seat_fender.py` 另检查黑色外滚边不存在、底壳内收、挡泥板与轮胎不相交，以及反光片位置具有侧裙承托。间隙与前口比例属于当前静态模型检查，不是厂方测量值。
